2026年10月1日， OpenAtom openEuler（简称"openEuler"或“开源欧拉”） 26.09 创新版本正式发布。作为汇聚全球开发者的创新平台，openEuler 持续在多样性算力、基础技术、全场景覆盖及生态服务等领域深耕。本次发布 6.6 与 6.18 双内核创新版本，AI 场景新增 Agent 可观测、SkillHub、上下文管理、KV Cache 协同加速、模型加载优化等特性；面向开发者和用户，增强 DevStation 智能开发者工作站开箱即用的能力，为开发者和用户带来全新体验。感谢来自社区834名开发者的贡献和支持，让我们携手同行，共建更好的openEuler。

- openEuler 26.09创新版本下载链接：<https://www.openeuler.org/zh/download/>

## AI场景创新

openEuler完成面向Agentic AI的技术升级，打造生产级AI操作系统底座。全新Agent Infra实现Agent调用全链路可观测、推理TTFT性能优化，兼顾安全可信、开箱即用、降本增效三大核心能力，为各行业AI智能体应用提供操作系统层面原生支撑。

- **Agent语义感知的KV Cache协同调度 ram-a-kv：** openEuler 26.09创新版本通过ram-a-kv将 Agent 上下文映射到KV Cache，预测重用关系，在下一次推理之前主动编排prefetch / evict，并通过全局引用计数保护跨会话共享的chunk，最终把TTFT压回毫秒级。

- **KV Cache聚合传输 MemFabric：** 本次版本实现了 decode 阶段 KV Cache 在节点内DDR+HBM 协同，在实际阶段按需加载，并聚合传输数据，有效缓解在高并发场景中由于HBM 内存不足，导致部分请求阻塞的情况，有效缓解高并发场景降低时延，提升BS及TPOT。

- **KV Cache多级缓存 LMCache-Ascend：** 本次版本构筑异构融合多级KV缓存池，不仅增强了自研KVC池化及PD传输能力，同时提供storagebackend生态接口，兼容mooncake、元戎datasystem等高性能分布式存储后端，端到端性能再度提升。

- **ModelFS用户态模型加载优化：** ModelFS在内核中设计了一个非侵入式、灵活且轻量级的可编程页缓存框架，允许用户自定义文件系统的页缓存策略。 

- **Agent可观测和治理 AcTrail&AgentCensor：** openEuler提供了一整套面向Agent可观测及运行治理的能力，包括基于系统旁路观测和治理的服务和插件框架底座AcTrail，及提供安全治理防护和基于AcTrail扩展富观测能力的AgentCensor。AcTrail是一套面向Agent的旁路观测和治理的服务和插件框架，通过无侵入的系统侧观测与跨层行为关联，将系统行为、模型交互和敏感访问处置统一到可追溯的Agent语义行为轨迹中，并提供灵活控制治理的底座能力，实现Agent的运行安全、稳定可靠、持续优化。AgentCensor 是一套面向 Agent 的非侵入式安全治理解决方案，无需改动 Agent、不干扰其推理过程。方案包括安全策略治理能力，支持安全策略快速配置、动态更新、热加载、低开销，并保障策略与执行的高一致性；同时提供基于 AcTrail 扩展的 Session级富观测和分层观测能力，为 Agent 运行过程带来更细粒度的可观测支撑。

- **数据引用减少上下文 SCCS：** Agent 执行长任务时，消息历史中会持续占用上下文窗口并推高 token 成本，openEuler 26.09创新版本通过压缩替换，按需取回等处理方式，给 Agent 的上下文装了一个"外部内存 + 换页机制"，让数据本体按需换入。

- **SkillHub：** 通过SkillHub把分散在各类代码托管平台上的 AI 技能统一汇聚、自动评估并公开分发，让开发者能够放心地发现、评估、使用和贡献 AI 能力。

## 服务器场景创新

在服务器领域，openEuler 26.09创新版本通过编排元技能、数据采集、场景化瓶颈分析、场景化调优执行四个核心skill的协同，将参数调优过程转化为由大模型推理驱动、可远程执行、可灰度回滚的自动化调优流水线。该能力适用于数据库、缓存、消息队列、大数据等业务在操作系统层的性能调优场景，能够快速定位瓶颈并落地可回滚的调优脚本。

## DevStation特性增强

DevStation是基于openEuler打造的智能开发者工作站，致力于为开发者提供开箱即用、高效、安全的开发环境。在openEuler 26.09创新版本中，DevStation进一步增强安装、AI Agent和软件包管理能力。

- **全新安装工具heolleo：** DevStation新增全新安装工具heolleo，采用 SquashFS 安装方案，显著压缩标准镜像体积，有效降低开发者镜像下载成本。同时，DevStation提供本地ISO安装模式，该模式可充分复用现有系统镜像文件，带来高速、可靠且完全离线的安装体验。

- **预装PolyMind，完善AI开发体验：** PolyMind是一个原生集成agentd服务的自托管AI Agent交互平台，已预装至DevStation。它将AI对话、Agent工作流编排与多模型管理融为一体，通过Agentd服务统一调度LLM、MCP 服务与Agent，实现多模态认知协作与自主决策。

- **集成epkg，简化软件环境管理：** DevStation集成epkg软件包机制，该机制采用用户态安装模式，软件包、环境及缓存均可存放于用户目录，实现宿主操作系统与项目软件环境的解耦，使软件依赖不再受制于宿主系统原生包管理器，能快速实现包括Agent等应用在openEuler环境上的安装部署体验。

从面向Agentic AI的基础设施能力，到服务器性能调优，再到面向开发者的智能工作站，openEuler 26.09创新版本持续拓展操作系统在不同应用场景下的技术能力。

未来，openEuler社区将继续坚持以开发者为中心，持续拥抱AI、拓展全场景能力，推动更多创新技术在社区沉淀与应用，为操作系统技术创新和开源生态发展持续注入新的动力。
